# Legacy

This folder contains code carried over from an earlier project.

## Why this code is here

When project direction shifted to Doctor Hunt, relevant already-built components were reused instead of starting from scratch. Some models, API logic, and UI code were kept in this repository for potential reuse.

## Status

- This code is not currently used anywhere in the Doctor Hunt app.
- It is kept here purely as a reference for future reuse when relevant features are implemented in Doctor Hunt.
- Naming, structure, and logic here reflect the original project and have not been adapted to Doctor Hunt's architecture or conventions yet.

## Notes

- Do not import or call this code directly from the active Doctor Hunt codebase without review and adaptation.
- If/when a feature here becomes relevant, move and refactor the needed parts into the main project structure rather than referencing this folder directly.
